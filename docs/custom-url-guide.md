# دليل استخدام الرابط المخصص (Custom URL)

## ما هو الرابط المخصص؟

الرابط المخصص (`custom_url`) هو ميزة تسمح لك بتوجيه مستخدم معين إلى صفحة محددة في لوحة الإدارة بعد تسجيل الدخول مباشرة.

## كيف يعمل؟

1. عند إنشاء أو تعديل مستخدم، يمكنك إضافة رابط مخصص في حقل "الرابط المخصص"
2. بعد تسجيل الدخول بنجاح، سيتم توجيه المستخدم تلقائياً إلى هذا الرابط
3. إذا لم يكن هناك رابط مخصص، سيتم توجيه المستخدم إلى لوحة التحكم الرئيسية (`/admin`)

## أمثلة على الروابط المخصصة:

### مثال 1: توجيه إلى صفحة شؤون التسجيل
```
/admin/registration-affairs
```

### مثال 2: توجيه إلى صفحة المستمسكات المطلوبة
```
/admin/registration-affairs/required-documents
```

### مثال 3: توجيه إلى صفحة الأخبار
```
/admin/news
```

### مثال 4: توجيه إلى صفحة البرامج
```
/admin/programs
```

### مثال 5: توجيه إلى صفحة طلبات التقديم
```
/admin/applications
```

## قواعد الاستخدام:

1. **يجب أن يبدأ الرابط بـ `/admin`**
   - ✅ صحيح: `/admin/news`
   - ❌ خطأ: `/news` أو `admin/news`

2. **يمكن أن يكون الرابط إلى أي صفحة داخل لوحة الإدارة**
   - صفحات موجودة: `/admin/news`, `/admin/programs`, إلخ
   - صفحات مخصصة: يمكنك إنشاء صفحات جديدة وتوجيه المستخدمين إليها

3. **الرابط اختياري**
   - إذا تركت الحقل فارغاً، سيتم توجيه المستخدم إلى `/admin` (لوحة التحكم الرئيسية)

## حالات الاستخدام:

### 1. مستخدم مسؤول عن شؤون التسجيل فقط
- **الرابط المخصص**: `/admin/registration-affairs`
- **الصلاحيات**: `registration.read`, `registration.manage`
- **النتيجة**: بعد تسجيل الدخول، يذهب مباشرة إلى صفحة شؤون التسجيل

### 2. مستخدم محرر للأخبار فقط
- **الرابط المخصص**: `/admin/news`
- **الصلاحيات**: `news.create`, `news.update`, `news.read`
- **النتيجة**: بعد تسجيل الدخول، يذهب مباشرة إلى صفحة الأخبار

### 3. مستخدم مشاهد فقط
- **الرابط المخصص**: `/admin` (أو فارغ)
- **الصلاحيات**: `news.read`, `programs.read`
- **النتيجة**: بعد تسجيل الدخول، يذهب إلى لوحة التحكم الرئيسية

## إنشاء صفحات مخصصة:

يمكنك إنشاء صفحات جديدة في `app/admin/(protected)/` وتوجيه المستخدمين إليها:

```
app/admin/(protected)/
  ├── my-custom-page/
  │   └── page.tsx
```

ثم استخدم الرابط:
```
/admin/my-custom-page
```

## ملاحظات مهمة:

1. **التحقق من الصلاحيات**: تأكد من أن المستخدم لديه الصلاحيات اللازمة للوصول إلى الصفحة المخصصة
2. **الأمان**: الرابط المخصص لا يمنح صلاحيات إضافية، فقط يوجه المستخدم إلى الصفحة
3. **التحديث**: يمكن تحديث الرابط المخصص في أي وقت من صفحة تعديل المستخدم

## مثال عملي:

لنفترض أنك تريد إنشاء مستخدم مسؤول عن إدارة المستمسكات المطلوبة:

1. **الاسم**: "مدير المستمسكات"
2. **البريد**: `documents@shau.edu.iq`
3. **الدور**: `MANAGER`
4. **الرابط المخصص**: `/admin/registration-affairs/required-documents`
5. **الصلاحيات**: 
   - `registration.read`
   - `registration.update`
   - `registration.delete`
   - `registration.manage`

عند تسجيل الدخول بهذا المستخدم، سيتم توجيهه مباشرة إلى صفحة المستمسكات المطلوبة!
